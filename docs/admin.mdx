The operator desk is `/admin` (`src/pages/Admin.tsx`). It is **not** linked from the marketing footer. It is not a salon login and it does not use `AppShell`.

## Auth

Requires `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, and `ADMIN_TOTP_SECRET` (Base32 secret enrolled in an authenticator app). If any are missing, login returns that admin is not configured.

Also requires Upstash Redis (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`). Sign-in is rate-limited to 5 failures per 15 minutes per IP+email; without Redis, login fails closed.

Sign-in needs email, password, and a current 6-digit TOTP (±1 step). It sets httpOnly cookie `nr_admin` (12 hours, SameSite=Lax, Secure on Vercel/production). Session check is HMAC (`api/_lib/adminAuth.ts`). Admin **POST**s require a same-origin `Origin` header matching the request host.

## What it shows

Paystack data is filtered to the **current secret key mode**. Test and live money are never mixed. Card numbers are not shown.

Sections include lookup by email, subscriptions, trial clock, R1 card check (a Paystack `reversed` transaction counts as refunded), transactions, refunds, disputes, failed renewals, abandoned checkout, 30-day money, CSV download, entitlement vs `/app`, who should have `/app`, plan health, site legal HEAD checks, and read-only recall wording (`DEFAULT_MESSAGE_TEMPLATE`).

**Repair** re-runs trial complete for R1 success without an open subscription (`POST /api/admin/repair` → existing `completeTrial`).

**Tenants** lists salon name, owner email, and plan from Postgres + Paystack — never client names. **Export this tenant** / **Restore this tenant** use the Settings JSON shape (`kind: newrecall-salon-book`), service role only, and write an audit row.

Platform backups are Supabase project backups / PITR. The desk reports that those exist rather than running a second backup worker.

**Support** and the **audit log** use Upstash (`admin:support`, `admin:audit`). Lists keep at most 200 rows and expire after 365 days.

## APIs

| Path | Role |
| --- | --- |
| `POST /api/admin/login` | Set session cookie |
| `POST /api/admin/logout` | Clear cookie |
| `GET /api/admin/session` | Current operator email |
| `GET /api/admin/overview` | Assembled lists and health |
| `GET /api/admin/lookup?email=` | One customer |
| `POST /api/admin/repair` | Finish stuck trial complete |
| `POST /api/admin/portal` | Paystack portal for a subscription |
| `POST /api/admin/support` | Support note (`book_locked` or `billing`) |
| `GET /api/admin/csv` | Billing CSV (`newrecall-billing.csv`) |
| `GET /api/admin/tenant-export?salonId=` | Tenant JSON book |
| `POST /api/admin/tenant-restore` | Restore tenant JSON (`salonId` + `backup`) |

Local Vite serves these through `vite.admin-api.ts`. Classification helpers are in `src/lib/adminClassify.ts` (shared with `api/_lib`).
