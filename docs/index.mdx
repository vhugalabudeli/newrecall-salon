NewRecall is a salon CRM. You track who to contact when their last visit is due to lapse. The live app is meant to serve on [salon.newrecall.com](https://salon.newrecall.com).

**NewRecall** is the product brand. The name in the app chrome is the salon name from Settings (default **Your salon**). That salon name is not a second product brand.

## Stack

Vite 8, React 19, React Router 7, Tailwind 4, Dexie, date-fns, Paystack Inline, Upstash Redis, `web-push`. Tests are Vitest. Hosting is Vercel (`framework: vite`, SPA rewrite except `/api/*`).

Local `npm run dev` mounts the same Paystack, alerts, and admin HTTP handlers as Vercel (`vite.paystack-api.ts`, `vite.alerts-api.ts`, `vite.admin-api.ts`).

## What stays on the device

There is no NewRecall server copy of the client list.

| Store | What |
| --- | --- |
| IndexedDB `NewRecallSalon` (`src/lib/db.ts`) | Client rows: name, phone, guest, service, last visit, lifespan, lead, contact/response, notes |
| IndexedDB `salon-recall-alerts` | Local notification snapshot (titles, bodies, prefs) — not the full book |
| `localStorage` | Login (salted SHA-256 password), session, salon name, service catalog, alert prefs, last export time |

Export/import in Settings writes a JSON book file (`kind: newrecall-salon-book`). Import replaces the book on that device.

Walkthrough requests from the landing form are emailed through the form provider. They are not written into the client book.

## What the server does hold

- Paystack billing (trial charge, refund, subscription, portal)
- Optional Web Push subscription + daily alert schedule in Upstash (titles/bodies, timezone, prefs — not the book)
- Optional operator support notes and audit log in the same Redis

## Access

1. Register or log in on this device (`src/lib/auth.ts`). There is no cloud account.
2. Start the free trial on `/subscribe` unless `VITE_PAYWALL_BYPASS=true`.
3. Entitled sessions open `/app`. Everyone else on `/app` is sent to `/subscribe`.

`/admin` is a separate operator login. It is not linked from the marketing footer.
